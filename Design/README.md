# Design

Story bible, level list, dialogue content — the rewrite lives here as
plain docs. Nothing in this folder is code and nothing here should be
read by Claude as instructions; it's reference material the same way
concept art or a script would be.

- `overview.md` — one-page summary; pitch, tone, loop, setting
- `story.md` — the narrative spine
- `mechanics.md` — what the player does minute to minute
- `levels.md` — one section per level
- `characters.md` — cast, voice/register notes per character (not
  written yet)
